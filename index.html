Instalação

Começar leva poucos passos.

O Zotero usa arquivos CSL para formatar automaticamente citações e listas de referências.

01

Escolha uma versão

Selecione autoria completa ou abreviada e abra o arquivo CSL pelo botão correspondente.

02

Instale no Zotero

Em Configurações → Citar → Estilos, use o botão + para instalar um arquivo CSL baixado, se necessário.

03

Revise o resultado

Escolha o estilo ao inserir citações no editor de texto e confira a saída com as orientações acadêmicas vigentes.

Sobre o projeto

Um trabalho que continua.

O projeto ABNT UFES foi desenvolvido para facilitar o uso de normas de citações e referências no Zotero. Os estilos originais foram disponibilizados à comunidade por meio do repositório internacional Citation Style Language.

Uma nova etapa de revisão está em desenvolvimento, à luz das normas recentes e dos materiais de normalização disponibilizados pela Biblioteca Central da UFES.
