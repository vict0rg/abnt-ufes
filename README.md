# ABNT UFES

Página de apresentação dos estilos CSL para uso no Zotero pela comunidade acadêmica da Universidade Federal do Espírito Santo.

- **Site:** https://vict0rg.github.io/abnt-ufes/ (após habilitar o GitHub Pages)
- **Código dos estilos:** https://github.com/vict0rg/csl-styles
- **Autoria dos estilos:** Victor Gianordoli e Saulo Caliman

## Estado do projeto

Os estilos disponíveis no repositório CSL são versões históricas. Sua revisão para as normas **ABNT NBR 10520:2023** e **ABNT NBR 6023:2025** está em desenvolvimento. A página inclui links para obtê-los, mas os resultados precisam ser conferidos antes de uso acadêmico final.

A atualização está sendo desenvolvida com auxílio de inteligência artificial generativa (ChatGPT, OpenAI), sob revisão e responsabilidade dos autores humanos.

## Publicar a página

O site é um único arquivo estático, `index.html`, sem compilação nem dependências.

1. Abra **Settings → Pages** deste repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch **main** e a pasta **/(root)**.
4. Clique em **Save** e aguarde o GitHub Pages publicar o endereço indicado acima.

Este é um projeto independente, não uma publicação institucional oficial da UFES.
